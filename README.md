# Store Inventory Management System

This is a simple yet effective inventory management system developed for **Mas Trade International Garments Ltd.** It was one of my very first projects as a beginner in software development. Despite its simplicity, the system continues to operate smoothly in a real business environment, and the client is happy with how well it handles their daily store operations.

I am currently not updating this project, as adding new features is time-consuming, and the existing functionality already serves the client's needs well.

## 🚀 Project Overview

- **Purpose**: Manage and track inventory items for Mas Trade International Garments Ltd.
- **Status**: Actively used in production
- **Client Feedback**: Very positive — simple and efficient

## 🛠️ Features

- ✅ Inventory Tracking: Keep records of stock levels
- ✅ Item Management: Add, update, and delete items
- ✅ User Interface: Simple and easy-to-use interface for staff
- ✅ Lightweight and fast

## 🧑‍💻 Technologies Used

- **Backend**: Python
- **Frontend**: HTML, CSS
- **Database**: SQLite

## 📦 Installation

To run this project locally, follow these steps:

1. **Clone the repository:**
```bash
git clone https://github.com/Ashikunnabi/StoreInventoryManagementSystem.git
```

2. **Navigate to the project folder:**
```bash
cd StoreInventoryManagementSystem
```

3. **Install required packages:**
```bash
pip install -r requirements.txt
```

4. **Run the application:**
```bash
python manage.py runserver
```

Then open your browser and go to \`http://127.0.0.1:8000/\`.
